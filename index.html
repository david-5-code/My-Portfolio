Arduino Projects

Detecting Image

This video demonstrates the image detection system using an ESP32-CAM. The ESP32-CAM is used to capture images of objects placed in front of the camera. The captured image is then processed and analyzed using the trained Edge Impulse image detection model to identify the object. In this demonstration, the system is trained to detect objects such as correction tape, lighter and clip. Once an object is detected, the system identifies its name and calculates its confidence level, which shows how confident the model is in its detection. The result is then displayed on the 16x2 I2C LCD, where the first line shows the detected object and the second line shows its confidence percentage. The ESP32-CAM continuously captures images and sends them to the classifier for analysis. If an object is detected, the LCD displays its label and confidence, such as “Correction Tape” with a corresponding percentage. If no object is detected, the LCD displays “Detecting...” while the system continues searching for an object.

Automated Parking System

This project is an Arduino-based automated parking system prototype designed to monitor parking slot availability. The system uses infrared sensors to detect whether a parking slot is occupied or vacant and displays the current status of each slot on an LCD screen. When a vehicle enters or occupies a parking space, the system detects its presence and automatically updates the corresponding slot status from “Free” to “Occupied.” The prototype also includes an automated barrier gate to demonstrate how vehicle entry and parking access can be controlled. The project combines Arduino programming, infrared sensors, LCD display, and servo motor control to create a simple smart parking solution. It demonstrates my skills in embedded systems, automation, sensor integration, and hardware programming, while showing how technology can be used to improve parking management and monitoring.
